## What is it?
It's an app that allows user to record their 3 moods throughout the day. Why 3 you may ask? Because based on my personal experience, even in my worst, mood-swing days, the maximum number of moods I could feel is 3. And that's 1 mood in the morning, afternoon, and night.

## How to run it?
For now it's Android-only, and everything lives on your own phone.
No account, no internet needed 🌙

1. Open the project in Android Studio
2. Plug in your phone (or start an emulator)
3. Press the green ▶ Run button, and that's it!

Want a ready-to-install file instead? The APK will be in the
Releases tab once the first version is out.
